# USECASE (Cockburn)

## 0. 이 문서의 형식

Cockburn 완전 서술형. 항목 ID는 `UC-{액터코드}{번호}`. 액터코드 H는 현업 사용자, A는 관리자(운영 개발자와 자사 DBA), S는 시스템(배치 스케줄러)이다. 사용자 목표 수준은 한 번의 이용으로 목표가 끝나는 것, 하위기능 수준은 사용자 목표 유스케이스가 포함(include)하는 내부 단계다. 확장은 `3a.` 형식이다.

## 1. 액터

| 코드 | 액터 | 실체 | 근거 |
|:--|:--|:--|:--|
| H | 현업 사용자 | 해외운송·KD·해외법인 담당자. VODA에서 단독 주소를 연다. 읽기만 한다 | [[TBL-SCN-001#P1]] |
| A | 관리자 | 운영 개발자(적재, 배치, 임계값)와 자사 DBA(매핑). 관리 화면 로그인 | [[TBL-SCN-001#P2]] [[TBL-SCN-001#P3]] |
| S | 시스템 | 새벽 배치 스케줄러와 파이프라인 7단계 | [[TBL-SCN-001#S4]] |
| 외부 | H-chat | 사내 LLM 게이트웨이. 사건 명명과 문장 생성에만 호출 | [[TBL-PRD-001#R14]] |
| 외부 | 데이터 제공자 | 현대차 CDO(완성차), 뉴스 API 시스템, 데이터서비스팀(블룸버그), GBP(Marklines). 파일로 전달 | [[TBL-PRD-001#R1]] |

## 2. 사용자 목표 수준 유스케이스

#### UC-H1 오늘의 브리핑을 본다

| 항목 | 내용 |
|---|---|
| 범위 | 인텔리전스 화면 |
| 수준 | 사용자 목표 |
| 주 액터 | H |
| 이해관계자와 관심사 | H: 오늘 볼 국가와 이유를 한눈에. 발주자: 발주자 메모 순서 준수 |
| 사전조건 | 새벽 배치가 한 번 이상 성공해 게시된 브리핑이 있다. H가 VODA에 로그인돼 있다 |
| 최소 보장 | 마지막 성공 브리핑이 기준일과 함께 표시된다 |
| 성공 보장 | 오늘 기준 헤드라인, 도메인 상태 3, 워치리스트가 2초 안에 표시된다 |
| 트리거 | H가 VODA 버튼으로 단독 주소를 연다 |
| 패키지 | briefing |
| 포함(include) | — |
| 확장점(extension point) | 4. 근거 확인 → [[#UC-H2]] · 5. 상세 → [[#UC-H3]] |
| 일반화 | — |

**기본 흐름**
1. 화면이 최신 게시 브리핑을 조회한다(LLM 호출 없음).
2. 시장지표 바에 4종 지표의 최신값, 변화율, 기준일을 보여준다.
3. 헤드라인 1문장과 "상관관계 확인 · 인과관계 미확정" 배지를 보여준다.
4. 도메인 상태 3카드에 신호등과 문장(강조 토큰 렌더)을 보여준다.
5. 워치리스트 카드를 신호등 순으로 보여준다. 신규·상승 배지가 있으면 붙인다.
6. H가 도메인 상태 영역을 접거나 편다. 상태는 브라우저에 기억된다.

**확장**
- **1a. 게시된 브리핑이 없다(첫 배치 전)**
  - 1a1. "브리핑이 아직 생성되지 않았습니다"와 다음 배치 예정 시각을 보여준다.
- **1b. 최신 브리핑이 강등본이다**
  - 1b1. 문장 자리에 템플릿 문장과 "요약 생성 실패, 판정값만 표시" 안내를 보여준다.
- **5a. 워치리스트가 비어 있다**
  - 5a1. "오늘 교차 확인된 국가 없음"을 정상 상태로 보여준다.

| 항목 | 내용 |

| 사전조건 | [[#UC-H1]]이 표시돼 있고 워치리스트 카드가 1건 이상 |
| 최소 보장 | 카드의 정형·비정형 신호 요약은 항상 보인다 |
| 성공 보장 | 사건, 기사 3건 이상, 시장 지표 원값, 각주 대응이 펼쳐진다 |
| 트리거 | H가 카드의 "근거 펼치기"를 누른다 |
| 패키지 | briefing |
| 포함(include) | — |
| 확장점(extension point) | 4. 기사 원문 → 새 창 |
| 일반화 | — |

**기본 흐름**
1. 카드가 정형 신호(값, 기준 방식), 재고 신호, 비정형 신호(사건 제목, 기사 수), CBU 비중, 관련 법인 태그를 보여준다.
2. H가 근거 펼치기를 누른다.
3. 사건별 기사(제목, 출처, 게시일, URL)와 시장 지표 원값(값, 변화율, 기준일)을 펼친다.
4. H가 기사 제목을 누르면 새 창으로 원문 URL을 연다. 화면은 외부 자원을 불러오지 않는다.
5. H가 요약 문장의 각주 번호를 누르면 해당 근거가 강조된다.

**확장**
- **1a. 법인 매핑이 없다**
  - 1a1. 태그를 "법인 미매핑"으로 보여준다.
- **1b. CBU/CKD 유도가 안 됐다**
  - 1b1. "노출 미확인"을 보여주고 신호등은 YELLOW 이하다.
- **3a. 라이선스 제한으로 기사 본문 비노출**
  - 3a1. 제목·출처·링크만 보여준다(미결).

#### UC-A1 데이터 파일을 적재한다

| 항목 | 내용 |
|---|---|
| 범위 | 관리 화면 |
| 수준 | 사용자 목표 |
| 주 액터 | A (운영 개발자) |
| 이해관계자와 관심사 | A: 행수·결측·매칭률 확인. 발주자: 원본 보존 |
| 사전조건 | A가 관리 화면에 로그인. 소스별 스키마 버전이 등록돼 있다 |
| 최소 보장 | 원본 파일이 보존되고 실패 사유가 이력에 남는다 |
| 성공 보장 | L0·L1까지 적재되고 결과 수치가 이력에 남는다 |
| 트리거 | A가 소스를 고르고 파일을 올린다 |
| 패키지 | ingest |
| 포함(include) | [[#UC-S6]] 회귀 검사 |
| 확장점(extension point) | 5. 백필 모드 |
| 일반화 | — |

**기본 흐름**
1. A가 소스(완성차 생산, 완성차 판매재고, 뉴스, 블룸버그, Marklines, 크로스워크)를 고르고 파일을 올린다.
2. 시스템이 원본을 보존하고 스키마 버전을 판별한다.
3. 시스템이 검증 결과(컬럼 대조, 기준 기간, 행수, 결측, 빈 골격 행, 중복 의심)를 보여준다.
4. A가 적재를 확정한다. 같은 기준일자가 있으면 덮어쓰기임을 안내한다.
5. 시스템이 L0 저장, L1 표준화, 미매핑 수집, 회귀 검사([[#UC-S6]])를 돌리고 결과를 이력에 남긴다.
6. A가 필요하면 해당 기간 배치 재실행([[#UC-A4]])을 요청한다.

**확장**
- **2a. 스키마 버전을 판별할 수 없다**
  - 2a1. 어느 컬럼이 다른지 보여주고 적재를 막는다. 새 버전 등록은 개발 작업이다.
- **5a. 백필 모드**
  - 5a1. 판정과 결합만 돌리고 LLM 명명·서술은 생략한다.
- **5b. 회귀 검사 급변**
  - 5b1. 적재는 완료하되 배치 자동 실행을 막고 A에게 확인을 요구한다.

#### UC-A2 매핑을 보강한다

| 항목 | 내용 |
|---|---|
| 범위 | 관리 화면 |
| 수준 | 사용자 목표 |
| 주 액터 | A (자사 DBA) |
| 이해관계자와 관심사 | A: 미매핑 목록을 받아 채움. 발주자: 매칭률 상승 |
| 사전조건 | 미매핑 목록이 존재한다 |
| 최소 보장 | 기존 매핑은 손상되지 않는다 |
| 성공 보장 | 마스터가 갱신되고 변경 이력과 영향 국가가 남는다 |
| 트리거 | A가 미매핑 목록을 내려받는다 |
| 패키지 | master |
| 포함(include) | — |
| 확장점(extension point) | 4. 과거 재계산 → [[#UC-A4]] |
| 일반화 | — |

**기본 흐름**
1. A가 미매핑 목록(소스, 값, 등장 횟수, 첫 등장일)을 내려받는다.
2. A가 크로스워크 엑셀의 해당 시트를 보강해 올린다.
3. 시스템이 매핑 차이(추가·변경·삭제)와 영향 받는 국가·공장을 보여준다.
4. A가 확정하면 마스터가 새 버전으로 갱신되고 다음 배치부터 적용된다. 과거 판정은 바뀌지 않는다.

**확장**
- **3a. 삭제되는 매핑이 있다**
  - 3a1. 삭제로 미매핑이 될 값의 건수를 경고하고 확인을 받는다.

**기본 흐름**
1. 국가×일 집계: 판매 3 플로우 합, 재고 4 스톡 말값, 생산 합, CBU 비중(생산 모델코드 유도).
2. as-of 조인: 시장지표는 기준일 이전 최신값, Marklines는 최신 기준월.
3. 비교값: 전년동월 있으면 YoY, 없으면 MoM. 기준 방식을 저장.
4. 정형 신호: 임계값(설정 현재 버전)으로 이상 판정. 당월 0이면 -100%.
5. 재고 체류 신호: 항해중·선적대기 비중.
6. 교차 확인: 정형 또는 재고 이상 AND 열린 사건(심각도 ≥ 임계, 건수 ≥ 최소)인 국가만 워치리스트.
7. 신호등: CBU 비중 ≥ 임계면 RED, 아니면 YELLOW. 노출 미확인이면 YELLOW 이하.
8. 법인 태그: glovis_entity 매핑, 없으면 "미매핑".
9. judgment에 사용 임계값 버전을 함께 저장한다.

**확장**
- **1a. 중복 적재 의심 일자**
