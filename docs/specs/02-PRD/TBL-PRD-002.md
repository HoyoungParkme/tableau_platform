# Glovis 완성차 인텔리전스 PRD

## 1. 목표

#### G1 리포트 4개, 각각 다른 인사이트

현업 담당자가 VODA에서 생산·판매·재고 대시보드 3본과 각각의 AI 인사이트 리포트(A1 생산, A2 재고, A3 판매. 자기 도메인 데이터만)를 보고, 종합 리포트(C)에서는 세 도메인의 변동을 가로질러 외부 원인 후보와 함께 "왜 이렇게 변했는가"를 본다. C는 세 리포트의 요약이 아니라 별개의 인사이트다. 근거: [[TBL-RFQ-002#Q1]] [[TBL-RFQ-002#Q12]] [[TBL-RFQ-002#Q13]] [[TBL-RFQ-002#Q14]]

#### G2 변동을 먼저 찾고, 원인은 리포트마다 다른 곳에서 찾는다

대시보드 데이터에서 감지된 변동이 출발점이다. A 리포트는 원인을 태블로 데이터 안에서 찾는다(어느 국가·차종·공장이 변동을 만들었나). C 리포트만 원인을 뉴스·시장 데이터에서 찾고 그 연관을 근거와 함께 보여 준다. 뉴스가 출발점이 아니다.

세 도메인이 외부와 만나는 폭은 같지 않다. 판매만 국가와 차종을 함께 가지고, 생산은 국가가 없으며, 재고는 원천 자체가 없다([[TBL-RFQ-002]] 4.2절). 국가 축이 없으면 뉴스와 만날 수 없으므로 C의 변동 카드는 판매와 그 유도값이 채운다. 생산은 도메인 상태 한 줄로만 들어간다. 근거: [[TBL-RFQ-002#Q21]] [[TBL-RFQ-002#Q25]] [[TBL-RFQ-002#Q26]] [[TBL-RFQ-002#Q13]]

#### G3 감지·후보·신호등은 코드, 설명과 문장은 LLM

변동 감지, 원인 후보 좁히기, 후보의 근접도 계산, 신호등 판정까지 결정적 코드가 한다. LLM은 후보 안에서 설명 문장을 쓴다. 모델이 등급이나 점수를 매기지 않는다. 매기면 왜 그렇게 매겼는지 답할 근거가 없고, 규칙이 계산한 값과 모델이 지어낸 값이 화면에서 같은 모양으로 보이기 때문이다. 화면의 모든 주장은 근거 행까지 추적된다. 근거: [[TBL-RFQ-002#Q24]] [[TBL-RFQ-002#Q35]]

#### G4 외부 데이터의 자산화

뉴스·블룸버그·Marklines와 현업 피드백을 우리 DB에 쌓는다. 오늘의 리포트 재료이자 다음 사업(예측)의 학습 데이터다. 근거: [[TBL-RFQ-002#Q29]] [[TBL-RFQ-002#Q33]]

#### G5 폐쇄망 납품 형상

폐쇄망 3컨테이너(postgres, backend, frontend), 사내 H-chat, VODA 단독 주소로 납품한다. 근거: [[TBL-RFQ-002#Q4]] [[TBL-RFQ-002#Q5]] [[TBL-RFQ-002#Q6]]

## 3. 요구사항

### 3.1 A 리포트 3개

#### R1 A 리포트 3개는 자기 데이터에서 인사이트를 뽑고 원인도 그 안에서 찾는다

근거: [[TBL-RFQ-002#Q12]] [[TBL-RFQ-002#Q14]] [[TBL-RFQ-002#Q13]] [[TBL-RFQ-002#Q16]] [[TBL-RFQ-002]] 4.2절

생산·판매·재고 대시보드마다 Nabi Agent 리포트가 하나씩 붙는다. 이름은 A1 생산, A2 재고, A3 판매다. 메커니즘(스냅샷, 판정, 글과 차트)은 브리핑 갈래 설계를 그대로 쓴다. 이 문서가 더하는 요구는 넷이다.

첫째, 트래킹 지표와 분해 차원이 도메인마다 다르다. 인입 샘플 실측으로 아래를 후보로 둔다. 현업 인터뷰로 확정한다.

| 리포트 | 트래킹 지표 | 분해 차원 | 쓸 수 없는 것 |
|:--|:--|:--|:--|
| A1 생산 | 사업계획 대비 달성률, 완성차 비중, 수출 비중 | 생산법인 28, 공장지역 18, 세부지역 41, 차종그룹 37, 차급 16 | 목적지 국가(없음), 파워트레인(절반 미분류), 원본 진도율 컬럼(개별 행 0) |
| A2 재고 | 유통 체류(유도), 재고 회전, 현지재고 | 국가, 차종 | 항해중·선적대기·법인·딜러 구분(원천 없음), 국가별 재고 시계열 |
| A3 판매 | 도매 대비 소매 격차(유통 체류율), 계획 대비 진도율, 전년 동월 대비 | 국가 29, 차종그룹 37, 대리점, 차급, CBU/CKD | 전 세계 국가별 차종(미주만 있음) |

둘째, 변동의 원인은 그 대시보드 데이터 안에서 찾는다. 변동이 난 지표를 위 차원으로 분해해 어느 항목이 변동을 얼마나 만들었는지를 보여 준다. 예를 들어 "도매 대비 소매 격차 5.0% 중 칠레가 25.2%"처럼. 이 분해는 결정적 계산이고 LLM은 결과를 문장으로 쓴다. 분해할 차원이 없으면 변동 판정만 보여 주고 분해 불가를 표시한다.

셋째, 외부요인(뉴스·블룸버그·Marklines)은 넣지 않는다. 외부 원인 탐색은 C 리포트([[#R10]] [[#R11]])만 한다.

넷째, 변동 판정값과 내부 분해 결과를 C가 읽을 수 있는 형태로 남긴다([[#R2]]).

- [ ] 세 리포트의 트래킹 지표 목록이 서로 다르고 각각 실측 컬럼에 근거한다
- [ ] 변동마다 기여 상위 항목(차원값, 기여도, 절대 대수)이 결정적으로 계산되어 저장되고 문장에 인용된다
- [ ] 세 리포트 어디에도 뉴스·시장지표 인용이 없다
- [ ] 각 리포트가 못 만드는 지표를 화면에 명시한다(A1 목적지 국가·파워트레인, A2 재고 4종·국가별 시계열, A3 전 세계 국가별 차종)
- [ ] 각 리포트의 변동 판정과 내부 분해가 도메인·국가(또는 공장)·기간 키로 조회된다

### 3.2 입력: A 판정 연결과 외부 데이터 적재

#### R2 A 리포트의 변동 판정을 C의 입력으로 받는다

근거: [[TBL-RFQ-002#Q12]] [[TBL-RFQ-002#Q13]] [[TBL-RFQ-002#Q16]]

A 리포트([[#R1]])가 대시보드 3본에서 매일 만드는 지표 스냅샷, 변동 판정, 내부 분해 결과를 C의 정형 입력으로 읽는다. 읽는 것은 판정값(지표, 값, 비교값, 기준 방식, 판정, 기여 상위 항목)이지 A가 쓴 문장이 아니다. C는 대시보드 수치를 다시 집계하지 않는다. 대시보드가 곧 집계 정의다. 국가 단위 변동을 만들려면 대시보드에 국가 차원 시트가 있어야 한다(미결). 없으면 [[#R3]]의 원장 집계로 보완한다.

A 리포트를 화면에서 열어 보여 주는 경로는 이와 별개다. 그 경로는 브리핑 갈래가 게시한 A 리포트를 문장·근거·버전까지 통째로 받아 게시 사본으로 둔다. C 생성은 판정만 읽고, A 열람은 사본을 읽는다.

- [ ] 대시보드 3본 각각의 스냅샷 판정이 도메인·국가·기간 키로 조회된다
- [ ] C가 쓰는 도메인 상태 수치가 대시보드 화면 수치와 일치한다
- [ ] 국가 차원 시트가 없는 지표는 집계 보완임이 결과에 표시된다
- [ ] C 생성 경로는 A의 문장을 읽지 않고, A 열람 경로는 게시 사본만 읽는다

#### R3 완성차 데이터 적재 (형태 두 가지)

근거: [[TBL-RFQ-002#Q31]] [[TBL-RFQ-002#Q32]] [[TBL-RFQ-002]] 4.2절

완성차 데이터의 형태가 둘이다. 적재기는 둘 다 읽어야 한다.

형태 A는 IF 원장이다. 생산 17열, 판매·재고 23열. 행마다 기준일자가 있다. 기준일자 단위 멱등 재적재가 가능하다.

형태 B는 피벗 리포트다. 인입 샘플의 실제 모양이다. 병합 헤더 2~3줄, 왼쪽에 차원, 그다음부터 (기간 블록 × 지표 종류). 행에 날짜가 없고 기간은 헤더에 일·월·누계·년으로 들어 있다. 적재기는 헤더를 펼쳐 (차원, 기간 구분, 지표 종류)에서 값으로 가는 긴 형태로 바꿔 저장한다. 기준일은 파일 단위로 하나 붙는다. 같은 기준일 파일을 다시 넣으면 덮어쓴다.

피벗 리포트의 전체 총계 행은 상세 행과 범위가 다르다. 실측에서 상세 행 합의 약 2.5배였다. 총계 행을 상세 행과 함께 더하면 값이 두 배 넘게 부푼다. 총계 행은 따로 보관하고 대조에만 쓴다. 적재 검증식은 상세 행 합만 쓰고, 총계 행과 상세 행 합의 차이는 경고로 남긴다.

어느 쪽이 정본인지는 미결이다(RFQ 6장 미정 1번). 둘 다 들어올 수 있다고 보고 스키마 버전으로 구분한다. 계획이 두 종류(운영계획·사업계획)이고 도매가 두 기준(실 도매·도매(공식))인 것은 지표 종류로 나란히 저장하고 어느 쪽을 쓸지는 설정으로 고른다. 정본은 설정 테이블의 새 버전으로만 바뀌고, 적재 요청이 정본을 정하지 않는다.

- [ ] 형태 A와 형태 B를 스키마 버전으로 자동 판별한다
- [ ] 형태 B의 병합 헤더가 기간 구분과 지표 종류로 펼쳐진다
- [ ] 형태 A는 기준일자 단위, 형태 B는 파일 기준일 단위로 멱등 재적재된다
- [ ] 운영계획·사업계획, 실 도매·도매(공식)를 둘 다 저장하고 설정으로 정본을 고른다
- [ ] 총계 행은 상세 행과 분리 보관되고 집계에 더해지지 않으며, 상세 행 합과의 차이가 경고로 남는다
- [ ] 결측은 NULL로 들어간다

#### R4 마스터·크로스워크 이관

근거: [[TBL-RFQ-002#Q35]] [[TBL-RFQ-002#Q36]] [[TBL-RFQ-002#Q37]] [[TBL-RFQ-002#Q38]] [[TBL-RFQ-002]] 4.2절

크로스워크 9시트를 테이블로 옮긴다. 국가(179), 생산공장, 뉴스 카테고리, 도메인 라우팅, 블룸버그 매핑. 판매 국가코드는 대리점 앞 3자리이며 실측으로 확인됐다(미국 B28AB, 캐나다 B06AA). 미매핑은 목록에 쌓는다.

- [ ] 판매에서 국가로, 생산에서 국가로, 뉴스에서 국가로 가는 매칭률을 적재마다 기록한다
- [ ] 미매핑 값이 목록으로 조회되고 엑셀 재업로드로 갱신된다

#### R5 뉴스 기사 적재

근거: [[TBL-RFQ-002#Q37]]

뉴스 API 결과를 기사 단위로 적재한다. 카테고리 8종, ISO3 다중 태그 분해, 점수, 요약, URL, 게시 시각. 가공본·원본 두 스키마 모두 읽고 정본은 가공본. FVL을 라우팅에 배정.

- [ ] result_id로 중복 제거, 국가 태그 분해, 라우팅 미배정 카테고리 0종
- [ ] 게시 시각 훼손 행은 일 단위로 대체하고 정밀도 플래그
- [ ] 기사의 출처명이 저장되어 사건별 출처 수를 셀 수 있다

#### R6 기사를 사건으로 묶고, 변동과 연결된 사건만 LLM이 이름 붙인다

#### R9 단계별 흐름의 어긋남을 재고 신호로 쓴다

근거: [[TBL-RFQ-002#Q31]] [[TBL-RFQ-002]] 4.2절

재고 원천이 없는 동안 재고 신호는 판매의 단계 차이로 만든다. 판매는 선적, 실 도매, 도매(공식), 소매 네 계열로 들어오므로 단계 사이의 차이가 곧 어디에 물량이 남아 있는지를 가리킨다.

두 구간을 본다. 법인 구간은 선적 빼기 도매 정본이며 법인 단계에 남은 물량이다. 화면 표기는 "법인 단계 체류"다. 딜러 구간은 도매 정본 빼기 소매이며 딜러 단계에 남은 물량이다. 화면 표기는 "유통 체류"다. 실측에서 미주 전체는 법인 구간이 2,350대로 거의 붙어 있고 딜러 구간이 34,104대(도매 정본 대비 5.0%)로 벌어졌다. 둘을 합치면 선적 대비 소매 36,454대다. 국가별로는 칠레 25.2%, 페루 21.2%가 크고 두 나라는 선적과 도매가 정확히 같아 물량이 딜러에서 멈춰 있다. 반대로 소매가 도매를 넘는 국가(푸에르토리코 -13.7%)는 이전에 쌓인 물량을 덜어내는 중이다.

격차율의 부호는 양수가 체류, 음수가 덜어냄이다. 화면이 감소 방향을 빼기 부호로 그리는 것은 렌더링 규칙이고 저장 값과 API 값은 이 부호를 따른다.

이 값은 유도값이며 재고 실측이 아니다. 화면에 유도임을 표시하고, 재고 원천이 들어오면 실측값으로 교체한다.

- [ ] 국가별로 두 구간의 차이와 비율이 계산되어 저장된다
- [ ] 음수(소매가 도매 초과)도 정상 값으로 다루고 방향을 표시한다
- [ ] 화면에 유도값임이 표시된다
- [ ] 재고 원천이 들어오면 같은 자리에 실측값이 들어가고 유도값은 참고로 내려간다

#### R10 변동마다 원인 후보를 코드가 찾고 근접도를 센다

근거: [[TBL-RFQ-002#Q21]] [[TBL-RFQ-002#Q26]] [[TBL-RFQ-002#Q37]] [[TBL-RFQ-002#Q13]]

C 리포트에서만 한다. [[#R2]]가 준 변동(도메인, 국가, 지표, 기간, 방향, 크기, A의 내부 분해 결과)마다 원인 후보를 결정적으로 뽑는다. 후보는 세 종류다. 그 국가(해협 귀속 포함)와 라우팅 카테고리, 시간창 안의 사건과 기사 상위 N. 같은 기간 시장지표의 변화(지표 바 4종 + 카테고리 연결 시리즈). 같은 국가의 다른 도메인 변동.

후보마다 코드가 근접도 값을 계산해 함께 저장한다. 값은 넷이다. 변동 시점과의 날짜 차이, 기사 수, 출처 수, 국가가 어떻게 걸렸는지(국가 직접·해협 귀속·같은 국가 다른 도메인·날짜만 일치). 이 값이 후보 정렬 순서와 신호등 판정([[#R16]])의 입력이다. 전부 셀 수 있는 값이라 왜 이 순서인지 화면에서 그대로 보여 줄 수 있다.

정렬 열쇠는 넷이다. 날짜 차이 오름차순, 출처 수 내림차순, 기사 수 내림차순, 그래도 같으면 후보 식별자 사전순. 넷째가 없으면 동률에서 순서가 흔들려 같은 입력에 같은 순서가 나온다는 약속이 서지 않는다. 넷째는 동률을 가르는 장치이므로 화면에 적는 정렬 규칙 문장에는 앞의 셋만 쓴다.

- [ ] 후보 목록이 변동별로 저장되고 다시 돌리면 같은 후보가 같은 순서로 나온다
- [ ] 후보마다 시점 차이·기사 수·출처 수·국가 일치 방식이 저장되고 화면에 그대로 표시된다
- [ ] 후보가 0건인 변동도 목록에 남는다("원인 후보 없음")
- [ ] 후보 상한(기본 사건 5, 기사 10, 지표 6)이 설정값이다
- [ ] 정렬 열쇠 넷이 계약으로 구현되고 화면 문구는 앞의 셋만 적는다

#### R11 H-chat은 후보 안에서 설명만 쓴다

근거: [[TBL-RFQ-002#Q21]] [[TBL-RFQ-002#Q22]] [[TBL-RFQ-002#Q27]]

변동 사실과 후보 목록(ID와 근접도 값)을 H-chat에 보내 연관 설명 문단과 인용할 후보 ID를 JSON으로 받는다. 등급이나 점수는 받지 않는다. 모델은 후보 밖의 사실을 쓸 수 없고 인과 단정 어휘를 쓸 수 없으며, 후보의 근접도 값을 바꾸거나 새로 만들 수 없다. 화면에는 "상관관계 확인 · 인과관계 미확정" 배지가 붙는다. 이것이 데이터 변동과 뉴스 사이의 공백을 메우는 자리이며, 메우는 것은 등급이 아니라 문장이다.

- [ ] 출력의 모든 인용이 입력 후보 ID 안에 있다(검증기)
- [ ] 출력에 등급·점수·순위를 뜻하는 필드가 없다
- [ ] 설명에 쓰인 수치가 전부 입력 후보의 근접도 값 또는 변동 사실과 일치한다
- [ ] LLM 실패 시 후보 목록과 근접도 값만 표시된다(강등)

#### R12 국가 × 기간 결합 테이블

근거: [[TBL-RFQ-002#Q21]] [[TBL-RFQ-002#Q35]] [[TBL-RFQ-002]] 4.2절

정형(A 스냅샷 판정 + 원장 보완 집계), 사건, 시장을 국가 × 기간 한 줄로 모은다. 감지·후보·설명의 재현 근거이자 2차 학습 테이블이다.

기간 단위는 데이터 형태를 따른다. 형태 A(IF 원장)가 들어오면 일자, 형태 B(피벗 리포트)만 들어오면 그 파일의 기준일과 기간 구분이다. 두 형태가 섞이면 일자를 기준으로 삼고 형태 B는 그 기준일에 붙인다.

결합 행에는 계획 값과 계획 정본 구분, 비교 값과 비교 방식이 함께 굳는다. 계획이 있으면 계획 대비를 먼저 본다는 규칙([[#R13]])이 보완 집계 경로에서도 서게 하려는 것이다. 비교 기준을 고르는 주체는 결합 단계이고 변동 판정은 굳은 값을 읽기만 한다.

- [ ] 한 행에 도메인별 변동 판정, 단계별 흐름 차이, CBU 비중, 사건 수·최대 영향도, 시장지표 as-of 값, 계획 값·정본 구분, 비교 값·비교 방식이 있다
- [ ] 기간 단위가 행마다 표시된다(일·월·누계·년)
- [ ] 실적이 있는 국가 전부에 행이 존재한다

#### R13 변동 감지 기준

근거: [[TBL-RFQ-002#Q35]] [[TBL-RFQ-002#Q17]] [[TBL-RFQ-002]] 4.2절

변동 감지는 A 스냅샷 판정을 따른다. C는 임계값을 재적용하지 않고 보완 집계에만 자체 임계값을 쓴다.

비교 기준. 계획이 들어 있으면 계획 대비를 먼저 본다. 계획이 없으면 전년 동월, 그것도 없으면 전월 대비로 내려가고 기준 방식을 표시한다. [[TBL-RFQ-002#Q17]]의 발주자 원칙(전년 동기)은 계획이 없을 때 적용된다.

감지 단위. 차종은 그룹 단위로 감지한다. 세부 차종 단위로 전년 대비를 돌리면 모델 교체가 -100%로 잡힌다. 규모는 작지 않다. 47개월 전체에서 전년 동월 판매가 0보다 컸는데 올해 0이 된 사례가 108건이고, 세부 차종 단위로 돌리면 이 108건이 전부 -100% 급락으로 잡힌다. 가장 큰 것은 그랜저 IG로 2023년 6월에 전년 동월 5,094대에서 0대가 됐다. 감지 단위를 잘못 잡으면 부호까지 뒤집힌다. 팰리세이드는 세부 차종 LX2로 보면 2024년 20,967대에서 2025년 1,403대로 93% 줄지만, 차종 그룹으로 묶으면 같은 기간 20,967대에서 55,291대로 2.6배 늘었다. 세부 차종은 분해에만 쓴다. 후속 모델 매핑 표가 들어오면 세부 차종 단위를 다시 본다.

시간 단위. 행에 날짜가 없는 형태에서는 일별 감지를 하지 않고 파일 기준일 사이의 변화를 본다.

- [ ] 변동마다 기준 방식(계획·YoY·MoM)과 비교 기간이 저장된다
- [ ] 차종 감지가 그룹 단위로 돌고 세부 차종은 분해에만 쓰인다
- [ ] 모델 교체로 사라진 세부 차종이 변동으로 잡히지 않는다(회귀 검사. 팰리세이드 LX2, 넥쏘 FE, 니로 DE PBV 세 건)
- [ ] 차종 그룹으로 합산하면 증가인 구간이 급락으로 보고되지 않는다(회귀 검사)
- [ ] 보완 집계의 임계값은 설정값이다

#### R14 재고 체류 신호

근거: [[TBL-RFQ-002#Q31]] [[TBL-RFQ-002#Q35]] [[TBL-RFQ-002]] 4.2절

재고 원천이 들어오면 항해중·선적대기 비중을 변동의 한 종류로 다룬다. 들어오기 전에는 [[#R9]]의 단계별 흐름 차이가 그 자리를 대신한다. 어느 쪽을 쓰고 있는지 화면과 저장 행에 표시한다. 원천이 없는 동안 재고 원천 구분은 유도로 고정하고 재고 네 칸은 비워 둔다. 중복 적재 의심 일자는 플래그와 "데이터 확인 필요".

- [ ] 재고 변동(실측 또는 유도)이 [[#R10]]의 후보 탐색 대상이 된다
- [ ] 실측인지 유도인지가 행에 저장되고 화면에 표시된다

#### R15 차종 노출 (CBU/CKD)

근거: [[TBL-RFQ-002#Q35]] [[TBL-RFQ-002#Q31]] [[TBL-RFQ-002]] 4.2절

국가별 CBU 비중을 쓴다. 인입 샘플에서는 판매에도 CBU/CKD 컬럼이 있어 그대로 읽는다. IF 레이아웃(형태 A)의 판매에는 없으므로 그때는 생산 모델코드로 유도한다. 유도 실패는 "노출 미확인"이고 신호등 규칙([[#R16]])의 입력이다. 유도 근거는 사람 말로 적는 메모이며 수치 점수를 두지 않는다.

- [ ] 형태 B는 컬럼을 그대로 읽고, 형태 A는 유도하며, 어느 경로인지 저장한다
- [ ] 유도 비율을 기록하고 실패 국가는 RED 불가

#### R16 워치리스트와 신호등은 규칙이 정한다

근거: [[TBL-RFQ-002#Q21]] [[TBL-RFQ-002#Q22]] [[TBL-RFQ-002#Q35]] [[TBL-RFQ-002]] 4.2절

워치리스트는 별도 판정이 아니라 변동 목록을 국가별로 묶어 정렬한 것이다. 신호등은 [[#R10]]의 근접도 값과 [[#R15]]의 노출로만 정한다. 모델의 판단은 들어가지 않는다.

세 조건을 본다. 첫째, 변동이 임계값을 넘었는가. 둘째, 같은 국가에 걸린 사건 후보가 근거 기준을 채웠는가(기사 수가 최소 이상, 출처 수가 최소 이상, 시점 차이가 시간창 이하). 셋째, 완성차 노출이 확인되는가. 셋을 다 채우면 red, 앞의 둘만 채우면 yellow, 사건 후보가 기준에 못 미치면 목록에는 남되 none. 임계값과 최소 건수는 설정값이다.

도메인 상태 3카드의 신호등도 같은 규칙의 산출물이다. 도메인 안 변동들의 신호등 최댓값을 쓴다. 생산은 국가 축이 없어 판정 대상이 아니므로 값이 notApplicable이고 화면 표기는 "판정 대상 아님"이다. "원인 미확인"과 다른 뜻이다. 목적지 국가 컬럼이 들어오면 그때 포함한다.

- [ ] 변동은 있는데 원인 후보가 없는 국가도 목록에 "원인 미확인"으로 남는다
- [ ] 신호등이 왜 그 색인지 화면에서 후보의 기사 수·출처 수·시점 차이로 확인된다
- [ ] LLM을 끄고 배치를 돌려도 변동 신호등과 도메인 상태 신호등이 같게 나온다
- [ ] 생산 변동이 국가 카드에 오르지 않고 생산 도메인 상태는 "판정 대상 아님"으로 표시된다
- [ ] 골든 배치: 형태 A 3개월 샘플이면 UAE·오만 red, 파키스탄 yellow. 형태 B 인입 샘플이면 칠레·페루가 체류 상위로 나온다

#### R17 관련 법인 신호등

근거: [[TBL-RFQ-002#Q23]] [[TBL-RFQ-002#Q36]]

국가에서 글로비스 법인으로 가는 매핑이 있으면 태그, 없으면 "법인 미매핑". 현대차 판매법인으로 대체하지 않는다.

- [ ] 매핑 없어도 오류 없이 표시, 들어오면 다음 배치부터 반영

#### R18 시점 고정과 재현

근거: [[TBL-RFQ-002#Q27]]

리포트는 생성 시점 스냅샷 기준. 변동·후보·근접도·신호등을 함께 저장해 재생성 시 같은 값이 나온다. LLM 문장만 달라질 수 있다.

- [ ] 리포트마다 기준 일시, 데이터 최신일, 후보 목록과 근접도 값이 저장된다

#### R19 현업 피드백을 라벨로 쌓는다

근거: [[TBL-RFQ-002#Q21]] [[TBL-RFQ-002#Q30]]

워치리스트 항목마다 현업이 "맞다·아니다·모르겠다"를 누를 수 있다. 사번과 시각을 함께 저장한다. 판정에는 즉시 반영하지 않고 2차(예측)의 라벨과 임계값 보정 재료로 쓴다. 1차 화면에 넣을지는 미결이다.

- [ ] 피드백이 변동·후보·설명 ID와 함께 저장된다
- [ ] 월별 동의율이 조회된다

### 3.4 C 리포트 생성

#### R20 LLM 입력은 판정된 사실과 고정된 후보만

근거: [[TBL-RFQ-002#Q22]] [[TBL-RFQ-002#Q27]] [[TBL-RFQ-002#Q29]]

설명 생성([[#R11]])과 문장 생성의 입력은 변동 사실, 후보 목록과 근접도 값, 노출, 제약 문구뿐이다. 원본 테이블을 넣지 않는다. 생성 후 숫자·날짜·인용을 대조한다.

- [ ] 항목당 입력 4KB 이하, 검증기 통과, 실패 시 강등

#### R21 종합 관점의 문장과 각주

근거: [[TBL-RFQ-002#Q18]] [[TBL-RFQ-002#Q24]] [[TBL-RFQ-002#Q13]] [[TBL-RFQ-002#Q14]]

헤드라인, 도메인 상태(생산·판매·재고), 변동별 요약을 생성한다. 도메인 상태 문장은 A 리포트의 문장을 복사하지 않고 C가 종합 관점에서 새로 쓴다. "생산은 어떻고, 재고는 어떻고, 판매는 어떻고, 외부와 같이 보니 이렇다"의 구조다. 즉 각 도메인의 변동을 다른 도메인 변동과 외부 원인 후보에 비추어 서술한다. 문장마다 각주가 근거 행으로 이어진다. 도메인 상태의 신호등은 [[#R16]]이 정하고 LLM은 문장만 쓴다.

생산 도메인 상태는 국가 축이 없으므로 외부 원인과 잇지 않고 공장·차종 사실만 말한다.

- [ ] 각주 없는 주장 0건, 각주 클릭 시 근거 원문
- [ ] 도메인 상태 문장이 A 리포트 문장과 동일하지 않다(표본 검사)
- [ ] 헤드라인이 두 도메인 이상 또는 도메인과 외부 원인을 함께 언급한다
- [ ] 생산 문장에 외부 원인 인용이 없다

#### R22 상관관계까지만 서술

근거: [[TBL-RFQ-002#Q28]] [[TBL-RFQ-002#Q21]]

인과 단정 금지, 배지 유지, 예측 어휘 금지 목록. 등급을 뜻하는 어휘(관련도 높음, 강한 연관)도 금지 목록에 넣는다.

- [ ] 위반 시 재생성 또는 강등

#### R23 강조 표시 계약

근거: [[TBL-RFQ-002#Q20]]

LLM은 강조 토큰만 출력하고 렌더링은 화면이 한다. 모델이 마크업을 직접 쓰면 화면마다 모양이 갈리고 검증할 수 없기 때문이다.

- [ ] 토큰 외 마크업 제거, 문장당 3개 이하

#### R24 이상징후 알림 이벤트

근거: [[TBL-RFQ-002#Q25]]

워치리스트 변화(신규·상승) 이벤트 기록과 배지. 채널 미결. 같은 리포트와 국가에 대해 재계산이 두 번 돌아도 이벤트는 한 행이다.

- [ ] 이벤트 테이블, 채널 없이도 실패 없음
- [ ] 리포트와 국가 조합으로 유일하다

### 3.5 화면 (구성은 비고정)

#### R25 화면 구성은 데이터가 받쳐 주는 만큼

근거: [[TBL-RFQ-002#Q15]] [[TBL-RFQ-002#Q18]] [[TBL-RFQ-002#Q19]]

개요 시트는 디자인 방향이다. C 리포트의 확정 구성은 시장지표 바, 헤드라인, 도메인 상태 3(종합 관점 서술, 접기 가능), 변동 목록(국가 묶음 = 워치리스트, 각 변동에 원인 후보·근접도 값·근거)이다. 법인 신호등은 매핑이 올 때까지 자리를 비운다. 순서는 발주자 메모를 따른다. A 리포트 3본은 좌측 사이드(출처·트래킹 지표·분해 차원·버전)와 중앙 지면(요약·지표 카드·분해·해설·고정 문구) 구조다.

- [ ] 표시 항목 전부가 인입 샘플로 채워진다(법인 태그 제외)

#### R26 변동 카드와 근거 펼치기

근거: [[TBL-RFQ-002#Q23]] [[TBL-RFQ-002#Q24]]

카드마다 국가, 신호등, 변동(지표·값·기준 방식), A의 내부 분해, 노출, 후보의 제목과 근접도 값(시점 차이·기사 수·출처 수), 연관 설명. 등급 표시는 두지 않는다. 근거 펼치기에 기사(제목·출처·게시일·링크)와 지표 원값, 설명에 쓰이지 않은 후보까지.

- [ ] 기사 3건 이상과 지표 원값, 외부 자원 불러오지 않음
- [ ] 후보 정렬 기준이 화면에 적혀 있다(앞의 세 열쇠)

#### R27 시장지표 바

근거: [[TBL-RFQ-002#Q38]]

4종 최신값·변화율·기준일. 이월 시 "기준일 지연". 이월이어도 네 칸을 비우지 않고 값과 이월 표시를 함께 내린다.

- [ ] 기준일 표시
- [ ] 이월 시에도 네 칸에 값이 있다

#### R28 상세 화면(2본째, 후보)

근거: [[TBL-RFQ-002#Q11]] [[TBL-RFQ-002#Q22]]

국가별 실적 표, 변동별 후보·연관 설명 전체, 시장 원값. 2본째를 만들지 여부와 구성은 미결이다.

- [ ] 카드에서 이동·복귀, 수치는 결합 테이블 값

#### R29 VODA 단독 주소

근거: [[TBL-RFQ-002#Q6]] [[TBL-RFQ-002#Q7]]

C 리포트는 VODA에 단독 주소로 이식된다. VODA 셸 없이 우리 백엔드만 부른다. A 리포트에서 C로 가는 화면 흐름은 없다(6.17). 현업 열람은 서명 토큰, 관리 화면은 세션이다.

- [ ] 셸 없음, 우리 백엔드만 호출
- [ ] A 리포트 화면에 C로 가는 링크가 없다

### 3.6 운영

#### R30 배치와 재실행

근거: [[TBL-RFQ-002#Q27]]

하루 1회. 단계는 여덟이다. 1 적재, 2 A 판정 읽기, 3 사건 묶음, 4 결합, 5 후보·근접도·신호등, 6 사건 명명, 7 연관 설명, 8 서술·게시. 판정은 5단계에서 끝나고 6~8단계는 읽을 수 있게 만드는 일이다. 실패 처리는 단계마다 다르다. 1·3·4·5단계 실패는 배치를 멈춘다. 2단계에서 A 판정을 못 받으면 보완 집계로 강등한다. 6~8단계 실패는 강등이며 판정 산출물은 그대로 게시된다. 회귀 급변은 경로에 따라 다르다. 수동으로 올린 파일은 적재를 마치되 자동 실행을 막고 관리자 해제를 기다리고, 배치가 스스로 집어 온 파일에서 만나면 배치를 멈춘다. 실패 시 이전 게시본 유지, 단계별 이력, 수동 재실행.

- [ ] 단계별 소요·건수·토큰 이력, 생성 실패 시 마지막 성공본 표시
- [ ] 6~8단계가 전부 실패해도 변동·후보·근접도·신호등·도메인 상태가 게시된다

### 3.7 비기능

#### N1 폐쇄망 동작

외부 의존 없이 돈다. LLM은 H-chat만 부른다. 외부 개발 단계에서는 OpenAI 계열을 쓰고 반입 시 설정으로 전환한다. H-chat 키는 코드·문서·저장소에 적지 않는다.

- [ ] 외부 의존 0, H-chat만
- [ ] 키가 저장소 어디에도 없다

#### N2 LLM 불능 시 강등

명명·설명·서술 세 지점이 각각 실패·필터·JSON 위반을 만나면 결정적 재료로 강등한다.

- [ ] 세 지점 모두 강등 경로가 있다
- [ ] 세 지점이 전부 실패해도 변동·후보·근접도·신호등·도메인 상태는 그대로 표시된다

#### N3 재현성

같은 기준일을 다시 돌리면 판정 산출물이 전부 같다.

- [ ] 변동·후보·근접도·신호등이 전부 동일. 설명 문장만 달라질 수 있다

#### N4 추적성

화면의 모든 수치·문장·인용이 저장 행으로 이어진다.

- [ ] 근거 없는 주장 0건

#### N5 열람 지연

열람은 게시된 결과만 읽는다.

- [ ] p95 2초, 열람 시 LLM 0회

#### N6 배치 시간

새벽 창 안에 끝난다.

- [ ] 4시간 창

#### N7 원본 보존

받은 파일은 그대로 보관한다.

- [ ] 파일 원본 보관

#### N8 데이터 품질 가시성

결측·중복·미매핑을 숫자로 볼 수 있다.

- [ ] 결측·중복·미매핑 수치 조회

## 5. ID 체계

## 6. 결정사항

상태 "제안"은 유저 승인 전, "확정"은 승인 후다.

### 6.1 ML(학습 모델)은 1차에 쓰지 않는다

상태: 제안. 학습 데이터 없음, 예측 대상 지표가 없음, 발주자 미요구, 운영 인력 미확인. 재검토 조건: 결합 테이블 12개월 + [[#R19]] 피드백 300건 + 발주자의 예측 지표 요구. 판매 월별 시계열 47개월이 확인돼([[TBL-RFQ-002]] 4.2절) 차종 그룹 단위 학습 데이터는 일부 있다. 국가 축이 없는 것이 여전한 제약이다.

### 6.2 LLM은 세 역할에만 쓴다

상태: 제안

| 역할 | 배치 단계 | 입력 | 출력 | 실패 시 |
|:--|:--|:--|:--|:--|
| 1. 사건 명명([[#R6]]) | 6 | 후보로 뽑힌 사건의 기사 상위 5 | 제목, 유형 | 대표 기사 제목 |
| 2. 연관 설명([[#R11]]) | 7 | 변동 사실 + 후보 목록(ID와 근접도 값) | 설명 문단, 인용 ID | 후보 목록과 근접도 값만 표시 |
| 3. 문장 생성([[#R21]]) | 8 | 판정·설명 결과 구조체 | 헤드라인, 도메인 상태 문장, 카드 요약 | 템플릿 문장 |

판정(변동 감지), 후보 좁히기, 근접도 계산, 정렬, 신호등, 매핑, 수치 계산에는 쓰지 않는다. 물량: 명명은 후보 사건만이라 일 수십 건, 설명은 변동 수(일 수십), 문장 약 65. 합계 일 20만~40만 토큰. A 리포트의 LLM 사용은 브리핑 갈래 설계를 따르며 여기 계수하지 않는다.

### 6.3 사건은 규칙으로 전량 묶고, 명명은 후보만

상태: 제안. 야간에 국가+카테고리+시간창 규칙으로 전량 묶어 사건 저장소를 유지한다(검색 대상). LLM 명명은 변동의 후보로 뽑힌 사건에만 한다. 임베딩 클러스터링과 전량 LLM 판독은 탈락. 해협 이슈는 해협에서 인접국으로 가는 표로 귀속.

### 6.4 변동 감지 기준은 A 판정, 비교는 계획 우선

상태: 제안. C는 A 스냅샷 판정을 그대로 받는다. 보완 집계에만 자체 임계값. 인입 샘플에 계획이 들어 있으므로([[TBL-RFQ-002]] 4.2절) 계획 대비를 먼저 보고, 없으면 전년 동월, 그다음 전월 대비로 내려간다.

### 6.5 원인 후보 검색은 구조화 조회, 벡터 RAG 없음

상태: 제안. 후보는 국가·카테고리·시간창·영향도로 SQL 조회. 기본계획의 "전용 RAG"는 이 구조화 조회와 후보 한정 LLM 입력을 뜻하는 것으로 설명한다. 대화형 질의가 2차에 오면 벡터 검색 재검토.

### 6.6 외부 데이터는 전부 적재하고 판정은 우리 DB에서 한다

상태: 확정(2026-09-15). 원천 시스템을 열람 시점에 조회하지 않는다. 판정의 재현성과 폐쇄망 동작이 이유다.

### 6.7 결합 단위는 국가 × 기간

상태: 확정(2026-09-15). 국가를 축으로 삼는다. 시간 축은 데이터 형태를 따른다. 행에 날짜가 있으면 일자, 없으면 파일 기준일과 기간 구분이다([[#R12]]).

### 6.8 워치리스트는 변동 목록의 국가 묶음이다

상태: 제안. 변동이 있으면 목록에 오르고, 후보의 근접도 값이 신호등을 정한다([[#R16]]). 변동 없이 뉴스만 급증한 국가는 오르지 않는다. 생산 변동은 국가 축이 없어 목록에 오르지 못한다.

### 6.9 뉴스 수집과 1차 분류는 발주자 시스템

상태: 제안. 뉴스 API가 카테고리와 국가 태그와 점수를 붙여서 준다([[TBL-RFQ-002#Q37]]). 우리는 그것을 받아 적재하고 사건으로 묶는다. 수집기와 분류기를 새로 만들지 않는다.

### 6.10 리포트는 배치로만, 사용자 새로고침 없음

상태: 제안. 열람은 게시본만 읽는다. 즉시 재생성은 LLM 호출을 열람 경로에 끌어들여 지연과 비용과 재현성을 깨뜨린다.

### 6.11 데이터가 먼저, 뉴스는 원인 탐색

상태: 제안(2026-09-16 유저 방향)

| 선택지 | 내용 | 판단 |
|:--|:--|:--|
| A. 데이터 주도 | 대시보드 변동 감지에서 그 변동의 원인 후보를 뉴스·시장에서 찾고 LLM이 설명 | 선택 |
| B. 뉴스 주도 | 뉴스 사건화에서 데이터로 확인하고 예측 | 탈락 |

근거: 발주자 요구가 "데이터 흐름과 비정형의 관련도"이고 대시보드가 이미 있다. 뉴스 처리량이 전량에서 변동 건수만큼으로 줄어 LLM 비용과 배치 시간이 내려간다. 뉴스 주도는 언급빈도 편향을 만든다.

적용 범위: 외부 원인 탐색은 C 리포트(과업지시 G10)만 한다. A 리포트(G3~G5)의 원인 탐색은 태블로 데이터 내부 분해([[#R1]])다.

공백: "이 변동이 이 뉴스와 관련 있는가"는 규칙만으로 답이 나오지 않는다. 그래서 감지·후보·근접도·신호등은 코드가 하고, 남는 공백을 메우는 설명 문장만 H-chat이 쓴다([[#R11]]).

재검토 조건: 피드백 동의율이 50% 미만이면 후보 규칙을 먼저 조정한다.

### 6.12 화면 구성은 고정이 아니다

상태: 확정(2026-09-16 발주자 설명, [[TBL-RFQ-002#Q15]]). 개요 시트는 디자인 방향. 표시 항목은 데이터 구조로 판단해 [[#R25]]로 확정한다.

### 6.13 정형 신호의 원천은 A 스냅샷, 원장 집계는 보완

상태: 제안

| 선택지 | 내용 | 판단 |
|:--|:--|:--|
| A. A 스냅샷 판정을 읽는다 | 대시보드가 집계 정의. C는 재집계하지 않음 | 선택 |
| B. 원장에서 C가 독자 집계 | 대시보드와 정의 불일치 위험 | 보완으로만 |

근거: 같은 국가의 판매 급감이 대시보드·A 리포트·C 리포트에서 다른 숫자로 보이면 신뢰가 무너진다. 다만 대시보드에 국가 시트가 없으면 뉴스와 만날 축이 없으므로 원장 집계를 보완으로 둔다.

### 6.14 관련도 등급을 두지 않는다

상태: 제안(2026-09-16 유저 지적)

| 선택지 | 내용 | 판단 |
|:--|:--|:--|
| A. 모델이 관련도 4단계를 매긴다 | 높음·중간·낮음·무관을 H-chat이 부여 | 탈락 |
| B. 코드가 센 값만 보여 준다 | 시점 차이, 기사 수, 출처 수, 국가 일치 방식 | 선택 |
| C. 규칙 점수를 하나로 합쳐 점수로 보여 준다 | 가중합 한 숫자 | 보류 |

근거: A는 왜 그 등급인지 답할 근거가 없고 같은 입력에서 재현되지 않는다. 발주자가 요구한 근거 추적([[TBL-RFQ-002#Q24]])과 어긋나고, 규칙이 계산한 값과 모델이 지어낸 값이 화면에서 같은 모양으로 붙어 읽는 사람이 둘을 구분할 수 없다. B는 전부 셀 수 있는 값이라 화면에 그대로 적을 수 있다. C는 가중치의 근거가 다시 임의가 되므로 현업 피드백이 쌓인 뒤에 본다.

영향: [[#R16]] 신호등이 규칙만으로 정해진다. LLM을 꺼도 신호등과 후보 순서가 그대로 나온다.

### 6.15 감지는 차종 그룹 단위, 세부 차종은 분해에만

상태: 제안(2026-09-16 실측)

| 선택지 | 내용 | 판단 |
|:--|:--|:--|
| A. 차종 그룹 단위로 감지 | 37개 그룹. 세부 차종은 기여 분해에만 | 선택 |
| B. 세부 차종 단위로 감지 | 97~146종. 후속 모델 매핑 표 필요 | 표 수령 후 재검토 |

근거: 판매 월별 시계열 실측([[TBL-RFQ-002]] 4.2절)에서 세부 차종 97종 중 47개월 내내 팔린 것은 8종뿐이다. 2025년 11월 전년 동월 대비로 전년 판매가 0보다 컸는데 0이 된 세부 차종은 팰리세이드 LX2 2,282대에서 0대, 넥쏘 FE 111대에서 0대, 니로 DE PBV 1대에서 0대 셋이며 그 달에는 이 셋뿐이다. 셋 다 후속 모델 전환이다. 47개월 전체로 넓히면 같은 사례가 108건이고 가장 큰 것은 그랜저 IG의 2023년 6월 5,094대에서 0대다. 세부 차종 단위로 감지하면 상시로 오탐이 깔린다.

부호가 뒤집히는 것이 더 강한 근거다. 팰리세이드 LX2는 세부 차종으로 2024년 20,967대에서 2025년 1,403대로 93% 줄었는데, 차종 그룹으로 묶으면 같은 기간 20,967대에서 55,291대로 2.6배 늘었다(LX2 1,403 + LX3 20,026 + LX3 HEV 33,862). 같은 데이터가 감지 단위에 따라 급락과 급증으로 갈린다. 감지 단위를 잘못 잡으면 성장하는 차종을 급락으로 보고하게 된다.

영향: [[#R13]] 감지 단위가 그룹이 된다. 성공지표에 모델 교체 오탐률 0건을 넣는다. 세부 차종은 [[#R1]]의 분해에만 쓰인다.

### 6.16 재고는 원천이 올 때까지 유도 지표로 간다

상태: 제안(2026-09-16 실측)

| 선택지 | 내용 | 판단 |
|:--|:--|:--|
| A. 단계별 흐름 차이로 유도 | 선적·도매·소매 사이의 차이를 체류로 본다 | 선택 |
| B. A2 리포트를 원천 수령까지 보류 | 리포트 4개 중 하나가 비게 된다 | 탈락 |
| C. 판매 월별 파일의 재고 컬럼을 쓴다 | 한 덩어리이고 국가가 없으며 MOS가 음수 | 탈락 |

근거: 인입 샘플 어디에도 항해중·선적대기·법인·딜러 재고가 없다([[TBL-RFQ-002]] 4.2절). 발주자 요구([[TBL-RFQ-002#Q16]] 재고 대시보드)는 이 넷을 전제한다. B는 리포트 4개 구조([[TBL-RFQ-002#Q14]])를 깨고, C는 값 자체가 신뢰할 수 없다(MOS 최솟값 -3.03). A는 국가 단위로 나오고 방향도 읽히며 실측으로 칠레 25.2%, 페루 21.2% 같은 구체적 차이가 확인됐다.

영향: [[#R9]] 신설. [[#R14]]가 실측과 유도를 구분해 저장한다. A2 리포트 화면은 유도값임을 명시하고 못 만드는 지표를 나열한다. 원천이 들어오면 같은 자리를 실측값으로 교체한다.

### 6.17 리포트 이름과 화면 흐름

상태: 확정(2026-09-16 유저). 리포트 이름은 A1 생산, A2 재고, A3 판매, C 종합이다. A 리포트에서 C 리포트로 들어가는 화면 흐름은 없다. C는 VODA 단독 주소로 따로 연다([[#R29]]).

### 6.18 판정은 5단계에서 끝나고 서술은 읽을 수 있게 만드는 일이다

상태: 제안. 배치 여덟 단계 중 1~5단계(적재, A 판정 읽기, 사건 묶음, 결합, 후보·근접도·신호등)는 결정적 코드이며 화면에 오르는 판정을 전부 확정한다. 6~8단계(명명, 설명, 서술·게시)는 LLM이 맡고 판정을 바꾸지 못한다. 세 지점이 전부 실패해도 1~5단계 산출물은 그대로 게시된다([[#R30]] [[#N2]]). 이 경계가 신호등 재현율 100%의 근거다.
